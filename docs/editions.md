# CALIBRA 앱 두 종류

개인용과 다인·교육용은 독립된 앱입니다. 한 앱의 설정을 바꾸어 다른 앱으로 전환하지 않습니다.

| 구분 | 개인용 | 다인·교육용 |
| --- | --- | --- |
| 버전 계열 | v0.1.x | v0.2.x |
| 바탕화면 | CALIBRA 개인용 | CALIBRA 다인·교육용 |
| 설치 폴더 | `%LOCALAPPDATA%\Programs\CALIBRA` | `%LOCALAPPDATA%\Programs\CALIBRA-Classroom` |
| 사용자 자료 | `%LOCALAPPDATA%\CALIBRA` | `%LOCALAPPDATA%\CALIBRA-Classroom` |
| 기본 주소 | `http://localhost:3000/` | `http://localhost:4000/` |
| 로그인 | 기존 개인 계정 유지 | 별도 관리자·교육생 계정 |
| 공개 배포 태그 | `v0.1.x` | `classroom-v0.2.x` |

두 앱은 같은 PC에서 동시에 실행할 수 있습니다. DB·첨부파일·공동 데이터·인증 키·로그인 쿠키·실행 빌드·업데이트 채널을 서로 공유하지 않습니다. 다인용 설치 시 개인용의 계정이나 업무 자료를 자동 복사하지 않습니다. 원본 자료를 다인용 교육에 사용하려면 파일을 명시적으로 불러오고 사본을 다른 이름으로 저장합니다.

게시글의 Excel/PDF 변환은 두 앱에 제공하며, 게시글 하나·선택한 게시글·게시판 전체를 내려받을 수 있습니다. 첨부파일 묶음이 아닌 등록된 게시글 내용을 변환합니다.

다인용은 설치 PC에서 최초 관리자 계정을 별도로 등록하고 공유를 켠 뒤 교육생에게 서버 IP와 **4000번 포트**를 안내합니다. 교육생은 같은 서버의 자료를 함께 사용하며, 수정 자료는 원본을 덮어쓰지 않고 사본으로 저장합니다. 25명 동시 사용 검증은 별도 시험 DB에서 진행하며 개인용 원본 자료를 시험에 사용하지 않습니다.

배포 파일은 빌드에 포함된 앱 종류·버전·빌드 번호가 일치할 때만 실행합니다. 다른 포트나 구버전으로 자동 우회하지 않습니다. 이 문서는 분리 기준이며, 설치·실행·동시 사용·공개 배포 완료 여부는 최종 검증 결과에 따릅니다.
