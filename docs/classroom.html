다수 사용하기 · 공동 교육 데이터

CALIBRA v0.2.0부터 서버 PC 한 대의 자료를 여러 PC·휴대폰에서 함께 사용하는 교육 구성을 제공합니다.

1. 서버 PC 준비

  1. 자료를 보관할 PC에 최신 Windows 설치 ZIP을 풀고 SETUP.exe로 설치·업데이트합니다. 서버의 접속 설정 기능은 새 설치 도구가 필요하므로 서버 PC는 전체 설치 ZIP으로 업데이트하세요.
  2. 관리자 로그인 후 홈의 ‘다수 사용하기’를 누르고 ‘사내망에서 이 PC에 접속 허용’을 켜서 저장합니다.
  3. 서버 PC의 CALIBRA 바로가기를 다시 실행합니다. 브라우저 새로고침만으로 실행 설정이 바뀌지는 않습니다.
  4. 화면의 IP와 포트를 교육생에게 전달합니다. 예: http://192.168.0.10:4000/. PC를 수업 중 켜 두고, 고정 IP 또는 DHCP 예약은 네트워크 관리자에게 요청하세요.

2. 교육생 접속

  1. PC의 ‘다수 사용하기’에서 서버 IP와 포트를 입력하고 ‘저장하고 새로고침’을 누릅니다.
  2. 휴대폰은 같은 Wi-Fi에서 전달받은 주소를 브라우저로 엽니다. 각 기기에 별도 DB를 설치할 필요가 없습니다.
  3. 서버에 등록·승인된 본인 이메일·비밀번호 계정으로 로그인합니다. Google OAuth는 localhost와 IP 주소의 설정이 달라 사내 IP 접속에는 승인된 일반 계정을 이용하세요.
  4. ‘공동 데이터실’을 열어 서버의 같은 자료 목록을 이용합니다. 다른 교육생의 저장 결과는 목록 새로고침으로 확인합니다.

3. 원본 보존과 데이터 불러오기

데이터 불러오기 → 사본으로 수정 → 다른 이름으로 저장

  • CSV·XLSX·JSON을 불러옵니다. CSV·XLSX는 첫 행을 그래프 양식의 열 이름과 같게 작성하고, XLSX는 첫 시트를 사용합니다.
  • JSON은 공동 데이터실에서 내보낸 파일을 다시 불러올 수 있습니다.
  • 원본과 저장된 수정본은 읽기 전용입니다. 수정하려면 사본으로 수정한 뒤 이전 자료와 다른 이름으로 저장하세요.
  • 새 저장본에 작성자·시각·이전 자료 번호가 남으며, 이전 파일을 덮어쓰지 않습니다. 원본 업로드 파일의 내용도 그대로 보관합니다.
  • 교육생은 기존 교육교재 원본을 수정·삭제할 수 없습니다. 교재 관리 작업은 관리자에게 요청하세요.

5. 동시 사용과 연결 점검

25명 규모 수업에서는 수업 전에 접속·자료 불러오기·동시 저장을 점검하세요. 모든 업무 DB와 첨부파일은 서버 PC에 보관하며, 여러 PC가 공유 폴더의 SQLite 파일을 직접 열지 않습니다. 기존 업무 관리 화면에서 같은 기록을 동시에 수정하면 나중 저장이 반영될 수 있으므로 교육 자료 수정은 공동 데이터실의 사본 저장을 이용하세요.

접속이 안 되면 서버 실행·주소·포트·같은 네트워크인지 확인하고, 방화벽은 관리자에게 해당 사설망에서 필요한 포트만 허용하도록 요청하세요. 인터넷에 포트 포워딩하지 않습니다. 장시간 고부하 쓰기나 중요 다중 사용자 운영에는 PostgreSQL 등 중앙 DB 구성과 별도 검증이 필요합니다.

6. 게시글 Excel·PDF 내려받기

게시판의 게시글 내려받기를 열고 Excel 또는 PDF를 선택합니다. 한 글만 받거나 여러 글을 선택하거나 게시판 전체를 한 파일로 받을 수 있습니다. 등록된 게시글 본문과 항목을 변환하며 첨부파일 ZIP을 만드는 기능이 아닙니다. 원본 게시글은 변경되지 않습니다.
