프로그램 화면 미리보기

아래 화면 카드를 누르면 큰 이미지로 자세히 볼 수 있습니다. 화면에 표시된 수치는 소개용 가상 데이터입니다.

미리보기는 프로그램 구성과 주요 화면을 설명하기 위한 이미지입니다. 실제 업무 데이터는 설치한 PC 안에 저장됩니다.

업무 기능 미리보기

실제 기능은 각 사용자의 PC에 설치한 앱에서 실행됩니다.

01

계측기 생애주기

등록, 관리번호, 바코드·QR, 위치, 불출, 검교정 및 폐기 이력을 관리합니다.

02

검교정 계획과 성적서

검교정 일정, 기관, 비용, 차기 일자와 연도별 성적서 자료를 기록합니다.

03

SPC · 공정능력

입력 데이터에 따라 관리도, 히스토그램, 공정능력 지표와 분석 보고서를 제공합니다.

04

Gage R&R · MSA

측정시스템 분석과 작업자별 반복·재현성 평가를 수행합니다.

05

교육과 절차

교육 자료, 참석·이수 정보, 업무 절차를 관리합니다.

06

비용과 보고

구매 검토, 검교정 비용 및 보고서 자료를 정리합니다.

설치와 사용 순서

소개 웹은 둘러보기용이며, 실제 데이터 관리는 설치 프로그램에서 합니다.

STEP 01설치 ZIP 다운로드
STEP 02압축 해제 후 SETUP.exe 실행
STEP 03바탕화면 CALIBRA 실행
STEP 04계정 로그인 후 업무 시작

다운로드 파일 안내: 퍼스널과 멀티은 별도 앱입니다. 각 앱의 GitHub 릴리스 Assets 중 퍼스널 또는 멀티 Setup ZIP 중 필요한 앱의 파일 한 개 받으세요. “Source code (zip)”와 “Source code (tar.gz)”는 개발용 소스 압축 파일이라 설치할 필요가 없습니다. 받은 설치 ZIP을 한 폴더에 저장한 뒤 압축을 풀고, 폴더 안의 SETUP.exe를 실행하면 됩니다. 퍼스널 설치 ZIP 다운로드 ↗

저장 위치와 여러 사용자 동시 사용기본 설치는 PC 로컬 자료를 사용하며, 공동 교육은 서버 PC 한 대에 접속하는 방식입니다. 공용 폴더의 SQLite DB를 여러 PC에서 동시에 여는 방식은 안전하지 않습니다. 사내망 공동 교육은 같은 서버의 자료를 불러와 사용하고, 원본을 보존하며 수정본을 새 이름으로 저장합니다. 장시간 고부하 운영에는 PostgreSQL 등 중앙 DB 구성과 별도 검증이 필요합니다.

자주 묻는 질문

설치와 데이터 보관에 관한 기본 안내입니다.

웹 주소를 다른 PC에서 열면 실제 업무 자료가 보이나요?

아니요. 소개 웹은 제품 안내와 미리보기용입니다. 업무 자료는 설치한 PC의 로컬 앱에 있습니다.

localhost 링크를 다른 PC에서 쓸 수 있나요?

아니요. localhost는 해당 PC 자신을 뜻합니다. 다른 PC에서는 각자 설치하거나, 다중 사용자 서버 구성을 사용해야 합니다.

설치 후 로그인이 필요한가요?

설치형 프로그램은 로그인 후 업무 화면을 사용하도록 구성합니다. 배포 시 이메일 계정 가입·승인 정책과 로그인 제공 방식이 운영 환경에 맞게 설정되어야 합니다.

무료 사용과 데이터 보관은 어떻게 되나요?

무료 배포를 목표로 하며, 개인 PC 설치형에서는 사용자의 업무 데이터가 해당 PC에 보관됩니다. 정기 백업을 권장합니다.
