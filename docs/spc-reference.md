# 통계적 공정관리 용어·계산식 · 6시그마

정의·분모·단위·적용 조건을 함께 확인합니다. 최소값·최대값 표기를 사용합니다.

## 기본 통계·데이터

| 용어 | 정의 | 계산식·방법 | 예제·조건 |
| --- | --- | --- | --- |
| 통계적 공정관리(SPC) | 시간순 자료로 공정 변동을 감시하고 원인을 조사하는 관리 활동 | 수집 → 측정체계 확인 → 관리도 → 원인·조치 → 재확인 | 관리상태와 제품 합격 여부는 별개의 판단입니다. |
| 모집단·표본 | 관심 대상 전체와 그중 조사한 일부 | 모집단 크기 N, 표본 크기 n | 시간·로트·설비의 대표성을 확인합니다. |
| 계량치 | 길이·무게처럼 수치로 측정한 특성 | x₁, x₂, …, xₙ | 단위를 함께 기록합니다. |
| 계수치 | 제품·결점·발생 사건을 센 자료 | 불량품수 d, 결점수 c, 검사수량 n | 불량품수와 결점수는 서로 다릅니다. |
| 평균 | 자료 값의 합을 자료 개수로 나눈 중심값 | x̄ = Σxᵢ/n | 2, 4, 6의 평균은 4입니다. |
| 가중평균 | 크기·수량에 따라 가중치를 반영한 평균 | x̄w = Σ(wᵢxᵢ)/Σwᵢ | 전체 불량품률은 시료별 비율의 단순평균 대신 Σdᵢ/Σnᵢ를 사용합니다. |
| 전체평균·총평균 | 부분군 평균들의 평균 | x̄̄ = Σx̄ᵢ/k | 부분군 크기가 같을 때 전체 원측정값 평균과 같습니다. |
| 중앙값 | 정렬한 자료의 가운데 값 | 홀수: 중앙 1개, 짝수: 중앙 2개의 평균 | 이상값의 영향을 평균보다 덜 받습니다. |
| 최빈값 | 가장 자주 나타나는 값 또는 계급 | 도수가 가장 큰 값·구간 | 최빈값이 여러 개일 수 있습니다. |
| 최소값 | 자료 중 가장 작은 값 | min(xᵢ) | 2, 4, 6에서 최소값은 2입니다. |
| 최대값 | 자료 중 가장 큰 값 | max(xᵢ) | 2, 4, 6에서 최대값은 6입니다. |
| 범위(R) | 최대값과 최소값의 차이 | R = 최대값 − 최소값 | 2, 4, 6의 범위는 4입니다. |
| 평균범위(R̄) | 여러 부분군 범위의 평균 | R̄ = ΣRᵢ/k | 전체 자료의 범위와 다릅니다. |
| 이동범위(MR) | 인접한 두 측정값 차이의 절대값 | MRᵢ = abs(xᵢ − xᵢ₋₁) | 2, 4, 6의 이동범위는 2, 2입니다. 첫 값은 없습니다. |
| 편차 | 각 값이 평균에서 얼마나 떨어졌는지 나타내는 부호 있는 값 | eᵢ = xᵢ − x̄ | 2, 4, 6의 편차는 −2, 0, 2이고 합은 0입니다. |
| 절대편차 | 편차의 크기 | abs(xᵢ−x̄) | 부호를 없앤 거리입니다. |
| 제곱합(SS) | 평균에 대한 편차 제곱의 합 | SS = Σ(xᵢ−x̄)² | 분산 계산의 분자입니다. |
| 표본분산 | 표본에서 산포를 추정한 값 | s² = Σ(xᵢ−x̄)²/(n−1) | n≥2. 단위는 원단위의 제곱입니다. |
| 모분산 | 모집단 전체의 평균 제곱편차 | σ² = Σ(xᵢ−μ)²/N | 모집단 전체를 계산하는 경우에 사용합니다. |
| 표본표준편차 | 표본분산의 양의 제곱근 | s = √[Σ(xᵢ−x̄)²/(n−1)] | 2, 4, 6의 표본표준편차는 2입니다. |
| 모표준편차(σ) | 모집단의 산포 | σ = √σ² | 표본표준편차 s와 기호를 구분합니다. |
| 자유도(df) | 추정에 사용되는 독립 정보의 수 | 표본분산의 df = n−1 | 분석 모형에 따라 자유도가 달라집니다. |
| 표준오차(SE) | 추정량의 표본추출 변동 | 평균의 SE = s/√n | 원자료의 표준편차와 다릅니다. 독립 표본 가정입니다. |
| 변동계수(CV) | 평균 대비 표준편차의 상대 크기 | CV = s/x̄ × 100% | 양수 비율척도에 적합하며 평균 0 부근에서는 부적절합니다. |
| 사분위수·IQR | 자료의 25%, 50%, 75% 위치와 가운데 50%의 폭 | IQR = Q₃−Q₁ | 사분위수 보간 방식에 따라 결과가 달라질 수 있습니다. |
| 표준점수(Z) | 기준 평균에서 표준편차 단위로 떨어진 거리 | z = (x−μ)/σ | 기준 모수와 사용한 표준편차를 명시합니다. |

## 도수·체크시트·QC 7가지 도구

| 용어 | 정의 | 계산식·방법 | 예제·조건 |
| --- | --- | --- | --- |
| 도수(f) | 유형 또는 계급에 속하는 자료 개수 | fᵢ = 해당 자료 개수 | 유형별·분포별 체크시트 모두 사용할 수 있습니다. |
| 상대도수 | 전체 도수 중 해당 도수의 비율 | fᵢ/Σfᵢ, 백분율은 ×100% | 분모가 0이면 계산할 수 없습니다. |
| 누적도수 | 정해진 순서까지 도수를 합한 값 | Fᵢ = Σ(j≤i)fⱼ | 계급은 값 순서, 파레토도는 도수 내림차순입니다. |
| 누적비율 | 누적도수를 전체 도수로 나눈 값 | Fᵢ/Σfᵢ ×100% | 마지막 값은 전체 도수가 양수일 때 100%입니다. |
| 계급·계급폭 | 측정값을 집계할 구간과 그 폭 | h = (최대값−최소값)/계급 수 | 경계 중복을 막고 마지막 구간에만 최종 상한을 포함합니다. |
| 수집용 체크시트 | 현장에서 발생·측정을 빠짐없이 기록하는 양식 | 네 세로선 + 다섯 번째 가로지르는 선 = 5개 묶음 | 12개는 5개 묶음 2개와 낱선 2개입니다. |
| 분석용 체크시트 | 수집 자료를 유형별·분포별 도수로 정리하는 표 | 유형·계급 / 체크 표시 / 도수 / 상대도수 / 누적값 | 불량 유형에만 한정하지 않습니다. |
| 파레토도 | 유형별 도수를 내림차순으로 정렬하고 누적비율을 함께 표시한 그림 | 좌축 최대=전체 도수, 우축 100%; 누적비율=누적도수/전체도수 | 첫 누적점은 첫 막대 상단에 맞춥니다. 80%는 참고선입니다. |
| 히스토그램 | 연속형 자료의 계급별 도수를 나타낸 분포 그림 | 동일 폭 계급의 높이=fᵢ | 계급폭이 다르면 면적 비교를 위해 도수밀도가 필요합니다. |
| 도수밀도 | 계급폭을 반영한 도수 | fᵢ/hᵢ 또는 fᵢ/(n hᵢ) | 막대 면적이 도수 또는 상대도수에 대응합니다. |
| 특성요인도 | 결과와 원인 가설을 가지 구조로 정리한 그림 | 결과 ← 주요 원인 ← 세부 원인 | 6M: 사람·설비·방법·재료·측정·환경. 원인은 검증해야 합니다. |
| 산점도 | 쌍을 이루는 두 변수의 관계를 점으로 표시한 그림 | (xᵢ,yᵢ) | 축 이름·눈금·단위가 필요하며 상관은 인과를 증명하지 않습니다. |
| 층별 | 설비·교대·로트 등 공통 요인으로 자료를 나누어 비교하는 방법 | 그룹별 원자료·평균·산포·표본수 | 평균만 비교하면 그룹 내부 분포 차이를 놓칠 수 있습니다. |
| 관리도 | 시간순 통계량을 중심선과 관리한계에 비교하는 그림 | 측정선 + CL + UCL + LCL | 동일 예시 그림의 선 모양을 재현하려고 데이터를 바꾸지 않습니다. |

## 관리도 공통 용어·판정

| 용어 | 정의 | 계산식·방법 | 예제·조건 |
| --- | --- | --- | --- |
| 부분군 | 짧은 시간·동일 조건에서 함께 수집한 측정 묶음 | 부분군 i의 측정값 xᵢ₁…xᵢₙ | 합리적 부분군은 군내·군간 변동을 구분하게 해 줍니다. |
| 부분군 크기(n)·부분군 수(k) | 한 묶음의 측정 개수와 묶음의 개수 | 전체 측정수 N=kn (동일 크기) | n과 k를 혼용하지 않습니다. |
| 중심선(CL) | 안정 공정의 중심을 나타내는 기준 | 통계량의 추정 평균 | 제품 목표값과 반드시 같지는 않습니다. |
| 관리상한(UCL)·관리하한(LCL) | 공정 변동으로 정한 이상 신호 기준 | 일반적인 Shewhart 관리도: CL ± 3×통계량의 표준편차 | 제품 규격에서 계산하지 않습니다. |
| 규격상한(USL)·규격하한(LSL) | 고객·설계가 정한 허용 범위 | LSL ≤ 제품값 ≤ USL (경계 규칙은 규격에 따름) | 관리한계 안이어도 규격을 벗어날 수 있습니다. |
| 우연원인·특별원인 | 공정에 내재된 변동과 특정 원인에 의한 변화 | 공식 없음; 공정 지식과 시계열 패턴으로 조사 | 관리도 신호만으로 원인을 확정하지 않습니다. |
| 관리상태·공정안정성 | 시간에 따라 변동 특성이 일관된 상태 | 관리한계·패턴 규칙·공정 변경 이력 검토 | 관리한계 내 모든 점이 있어도 연속 패턴 신호가 있을 수 있습니다. |
| OOC·OOS | 관리상태 이탈과 규격 이탈 | OOC: 관리한계·규칙 신호 / OOS: 제품 규격 이탈 | 서로 다른 판정입니다. |
| Phase I·Phase II | 초기 기준선 설정 단계와 이후 감시 단계 | Phase I: 특별원인 조사 후 기준 확정 / Phase II: 고정 기준으로 감시 | 새 점마다 한계를 자동 재계산하면 변화를 숨길 수 있습니다. |
| ARL·오경보 | 신호까지 평균 점 수와 정상 공정에서의 잘못된 신호 | 독립 신호확률 α일 때 ARL₀=1/α | 정규 3σ 단일 규칙의 α≈0.0027, ARL₀≈370입니다. |
| Nelson N1~N4 | 3σ 초과, 중심선 한쪽 연속, 추세, 교대 패턴 | N1:1점>3σ; N2:9점 한쪽; N3:6점 증가/감소; N4:14점 교대 | 규칙 종류·방향·경계 처리 기준을 함께 기록합니다. |
| Nelson N5~N8 | 특정 σ 영역에서 나타나는 군집·회피 패턴 | N5:3점 중2점 같은쪽>2σ; N6:5점 중4점 같은쪽>1σ; N7:15점 ±1σ 안; N8:8점 ±1σ 밖 | 여러 규칙을 동시에 적용하면 오경보율이 높아집니다. |

## 관리도별 계산식

| 용어 | 정의 | 계산식·방법 | 예제·조건 |
| --- | --- | --- | --- |
| X̄-R 관리도 | 동일 크기 부분군의 평균과 범위를 감시 | X̄: CL=x̄̄, UCL/LCL=x̄̄±A₂R̄; R: CL=R̄, UCL=D₄R̄, LCL=D₃R̄ | A₂·D₃·D₄는 부분군 크기별 계수. R을 먼저 해석합니다. |
| I-MR 관리도 | 시간순 개별값과 이동범위를 감시 | I: CL=x̄, UCL/LCL=x̄±3MR̄/1.128; MR: CL=MR̄, UCL=3.267MR̄, LCL=0 | MR은 인접 2개 기준입니다. |
| X̄-S 관리도 | 동일 크기 부분군의 평균과 표준편차를 감시 | X̄: x̄̄±3s̄/(c₄√n); S: s̄[1±3√(1−c₄²)/c₄] | S 하한은 0 이상. 군내 표준편차는 표본표준편차입니다. |
| P 관리도 | 검사수량 대비 불량품률을 감시 | pᵢ=dᵢ/nᵢ, p̄=Σdᵢ/Σnᵢ, CL=p̄; UCLᵢ/LCLᵢ=p̄±3√[p̄(1−p̄)/nᵢ] | 검사수량이 다르면 한계가 변합니다. 한계는 0~1로 제한합니다. |
| Pn(np) 관리도 | 일정한 검사수량의 불량품수를 감시 | CL=np̄; UCL/LCL=np̄±3√[np̄(1−p̄)] | 검사수량 n은 일정. 한계는 0~n으로 제한합니다. |
| C 관리도 | 일정한 검사 기회의 결점수를 감시 | c̄=Σcᵢ/k; CL=c̄; UCL/LCL=c̄±3√c̄ | 검사 단위·면적·시간이 일정해야 하며 하한은 0 이상입니다. |
| U 관리도 | 검사 크기가 다른 자료의 단위당 결점수를 감시 | uᵢ=cᵢ/nᵢ, ū=Σcᵢ/Σnᵢ; UCLᵢ/LCLᵢ=ū±3√(ū/nᵢ) | 검사 크기는 양수이며 소수 면적·시간도 가능합니다. 하한은 0 이상입니다. |
| EWMA | 과거 자료에 지수 가중치를 주어 작은 이동을 감시 | zᵢ=λxᵢ+(1−λ)zᵢ₋₁; 한계=μ₀±Lσ√[λ/(2−λ)×(1−(1−λ)²ⁱ)] | 독립 개별값 기준 식. 0<λ≤1, 초기값·L 설정 필요. 학습용 항목입니다. |
| CUSUM | 목표 대비 누적 편차로 작은 이동을 감시 | C⁺ᵢ=max(0,C⁺ᵢ₋₁+xᵢ−μ₀−K), C⁻ᵢ=max(0,C⁻ᵢ₋₁+μ₀−K−xᵢ) | 누적값이 H를 넘으면 신호. K·H·표준화 여부 설정 필요. 학습용 항목입니다. |

| 결점·부적합 | 충족되지 않은 요구 조건의 개별 발생 건 | 제품 1개에서 결점 c개 집계 가능 | 불량품수와 달리 제품수보다 많을 수 있습니다. |
| 불량품률·불량률 | 검사한 제품 중 불량품의 비율 | 불량품수/검사수량 ×100% | 1000개 검사 중 불량품 20개면 2%입니다. 검사 단계·기간을 명시합니다. |
| 결점률·DPU | 검사 제품당 결점 건수 | DPU=결점수/검사제품수 | 1000개에서 결점 30건이면 0.03건/개. 불량품률 3%라는 뜻은 아닙니다. |
| PPM | 백만 제품당 불량품 수 | 불량품수/검사제품수 ×10⁶ | 20/1000×10⁶=20000 PPM입니다. 지표 분모를 명시합니다. |
| 불량 기회(Opportunity) | 제품에서 결점이 발생할 수 있는 사전 정의된 검사 기회 | 총 기회수=Σ제품별 기회수 | 제품별 기회수가 같으면 제품수×개당 기회수. 지표 개선을 위해 임의로 늘리지 않습니다. |
| DPO | 기회당 결점 비율 | DPO=결점수/총 불량 기회수 | 제품수와 기회수의 분모를 구분합니다. |
| DPMO | 백만 기회당 결점 수 | DPMO=DPO×10⁶ | 1000개×4기회에서 20결점이면 5000 DPMO입니다. |
| 양품률·합격률 | 정해진 검사 단계에서 합격한 제품 비율 | 합격수/검사수 ×100% | 재작업 포함 여부·중복 재검사 제외 여부를 정해야 합니다. |
| 직행률(FPY·FTY·FTR) | 재작업·수리·재검사 없이 처음 통과한 비율 | 최초 합격 제품수/최초 투입 제품수 ×100% | 1000개 투입, 950개 최초 합격이면 95%입니다. |
| 최종 합격률·최종 수율 | 재작업 후 회복품을 포함한 최종 합격 비율 | 최종 합격 제품수/최초 투입 제품수 ×100% | 최초 950개와 재작업 회복 40개면 990/1000=99%. 직행률은 여전히 95%입니다. |
| 종합 직행률(RTY) | 정의한 연속 경로를 모든 공정에서 최초 통과할 확률 지표 | RTY=∏공정별 최초 통과 비율 | 0.95×0.98×0.97=0.90307, 즉 90.307%. 동일 경로·모집단·집계 조건을 명시합니다. |
| 정규화 수율 | 공정 수를 고려한 단계당 기하평균 수율 | Ynorm=RTY^(1/k) | 단계 수가 다른 공정을 비교할 때 정의를 함께 제시합니다. |
| 포아송 무결점 수율 | 포아송 결점 모형에서 결점 0개일 확률 | Y₀=exp(−DPU) | 모형 추정치이며 실제 관측 직행률과 동일하다고 가정하지 않습니다. |
| 재작업률 | 요구 조건을 충족하도록 다시 작업한 제품의 비율 | 재작업 대상 고유 제품수/최초 투입수 ×100% | 반복 횟수를 세는 작업 건수 지표와 구분합니다. |
| 수리율 | 수리 대상으로 처리한 제품의 비율 | 수리 대상 고유 제품수/정의한 기준 수량 ×100% | 수리와 재작업의 승인·판정 조건은 조직 절차를 따릅니다. |
| 재검사율 | 다시 검사한 제품의 비율 | 재검사 대상 고유 제품수/최초 검사 제품수 ×100% | 단순 반복 측정과 재검사를 구분합니다. |
| 폐기율 | 회복하지 못하고 폐기한 제품의 비율 | 폐기수/최초 투입수 ×100% | 공정 경로·재공·기간 차이가 있으면 단순히 100−최종 수율이 아닐 수 있습니다. |
| 유출 불량률 | 지정 검출 단계 이후에 발견된 불량 비율 | 유출 불량품수/정의한 출하·검사 수량 ×100% | 출하 기준·고객 반품 기준 등 분모와 기간을 고정합니다. |
| COPQ·품질비용 | 내부·외부 실패 등 품질 손실 비용 | 실패비용=재작업+폐기+반품·보증 등 정의한 비용 | 예방·평가 비용을 포함하는 총 품질비용과 구분합니다. |

| 용어 | 정의 | 계산식·방법 | 예제·조건 |

| 공정 내 σwithin | 부분군 내부 변동으로 추정한 표준편차 | X̄-R: σwithin=R̄/d₂; X̄-S: s̄/c₄; I-MR: MR̄/1.128 | 부분군 구조와 추정 방법을 기록합니다. |

| Cp | 공정 내 변동 대비 규격 폭 | Cp=(USL−LSL)/(6σwithin) | 중심 치우침은 반영하지 않습니다. LSL<USL, σwithin>0이어야 합니다. |
| Cpk | 중심 치우침을 반영한 공정 내 능력 | Cpk=min[(USL−x̄)/(3σwithin),(x̄−LSL)/(3σwithin)] | 평균이 규격 밖이면 음수일 수 있습니다. |

| Pp·Ppk | 전체 산포 기준 공정성능 | Pp=(USL−LSL)/(6soverall); Ppk=min[(USL−x̄),(x̄−LSL)]/(3soverall) | Cp·Cpk와 표준편차 추정 기준이 다릅니다. |
| Cpm | 목표값과의 차이까지 반영한 지수 | Cpm=(USL−LSL)/(6√[σ²+(μ−T)²]) | 목표 T와 σ 추정 기준을 명시합니다. |
| 정규모형 예상 규격 이탈률 | 정규분포를 가정한 규격 밖 확률 | Φ((LSL−μ)/σ)+1−Φ((USL−μ)/σ) | 실제 관측 불량률과 별도로 표시하며 정규성·안정성을 확인합니다. |

| N4 | 14점 연속 위아래 방향 교대 | 주기성·과잉 조정 가능성 | 설비 주기·작업 교대·반복 조정 이력을 확인합니다. |
| N5 | 연속 3점 중 2점이 같은 쪽 2σ 초과 | 평균 이동 가능성 | 해당 구간과 직전 정상 구간의 공정 조건을 비교합니다. |
| N6 | 연속 5점 중 4점이 같은 쪽 1σ 초과 | 작은 중심 이동 가능성 | 조건 변화와 측정 체계의 변화를 추적합니다. |
| N7 | 15점 연속 중심선 ±1σ 안 | 산포 축소·층별 혼합·측정 분해능 문제 가능성 | 부분군 구성·반올림·분해능·실제 개선 여부를 확인합니다. |
| N8 | 8점 연속 ±1σ 밖이며 중심선 양쪽에 분포 | 공정 혼합·층별 차이 가능성 | 설비·로트·작업조별로 자료를 나눠 원인을 조사합니다. |

## 조치 기준

제공 교재 26~33쪽의 관리도 구성·산포·검증·이탈 처리 원칙을 기준으로 작성했습니다.

1. 시료·부분군·시각·로트·설비·규칙·현재 한계를 기록합니다.
2. R/S/MR 산포 이상 시 평균의 안정 판정을 보류합니다.
3. 입력·측정 오류와 영향 범위를 확인하고 책임자에게 알립니다. 위험에 따라 공정·출하 보류 및 영향품 식별·격리·재검사를 수행합니다.
4. 1차 조치로 특별원인을 제거하고 공정을 안정화합니다. OOS는 별도 부적합품 절차로 처리합니다.
5. 2차 조치로 근본원인·재발방지·담당자·기한·효과를 기록하고 관리계획과 표준작업을 갱신합니다.
6. 수율 상승·결점 감소 같은 개선 방향의 변화도 원인을 검증하고 유지 조건을 표준화합니다.
7. 조치·원인·승인이 확인된 초기 기준선의 사본에서만 제외 사유를 기록하고 재계산합니다. 미조치 점을 임의로 제외하지 않고 원문을 보존합니다.
8. 승인된 기간·표본수로 효과를 검증하고 책임자 승인 후 재개합니다. 한 번 정상이라고 자동 해제하지 않습니다.
